# MoonWeb — one-click Windows build

This repository is designed so a normal Windows user does not need Node.js, Linux, or a compiler.

1. Upload the repository contents to GitHub, including `.github/workflows/build-windows.yml`.
2. Open **Actions**.
3. Select **Build MoonWeb installer**.
4. Click **Run workflow** → **Run workflow**.
5. Wait for the green check.
6. Open the completed run and download the **MoonWeb-Windows-Installer** artifact.
7. Extract the downloaded artifact and run `MoonWeb-Setup-1.0.0-x64.exe`.

The installer is an NSIS installer generated by electron-builder and bundles Electron's Chromium runtime. It does not launch Microsoft Edge.

## Important product limitations

- The current MoonWeb search option is a browser-shell search route, not an independently crawled search index.
- The current VPN button does not claim a VPN connection; a real Windows VPN requires a provider/profile and native WireGuard/Wintun integration.
- Chromium extension loading is supported for unpacked extensions. Direct Chrome Web Store installation is not guaranteed by Electron.
